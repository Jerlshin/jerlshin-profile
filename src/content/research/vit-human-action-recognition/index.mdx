## Scope

Recognising an action from a still image removes the cue that video methods lean on hardest —
motion. What remains is pose, object context, and scene, and a model has to weigh those against each
other differently depending on the action.

The work separates two evaluation regimes that are often conflated:

- **Domain-based recognition**, where the label set and the imagery come from one constrained
  source, and a model can exploit consistent framing and context.
- **General recognition**, where neither holds, and context that helped in the first regime becomes
  a shortcut that actively misleads.

Reporting a single aggregate number across both hides exactly the failure this separation is meant
to expose.
